## Tool and quality provenance

Use the session's exposed tool schemas and actual account entitlement rather than stale API names or inferred plugin access. During the system audit, 21st free metadata search worked while hosted generation was disabled; this is dated evidence, not a permanent account guarantee. Cached bundles, enabled plugins, connector authorization and healthy calls are separate states. Do not install plugins or change permissions merely to satisfy a design task without the applicable authorization.

Repository role and skill files do not grant extra filesystem permission. Snapshot/path checks are verification, not process attribution or isolation. Preserve concurrent workspace changes and record their origin/limits rather than silently attributing them to the current specialist. Only measured checks support acceptance; “perfect” and “production-ready” are not outcomes established by source parsing alone.
