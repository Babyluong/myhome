# T-010 — Module Hub High-Craft "Depth" Design & Ergonomics Overhaul

**Goal:** Overhaul `ModuleHubPage.tsx` to meet the H.O.M.E. Modern Depth design standard and TasteSkill clinical density (7-8). Consolidate executive header real estate, eliminate redundant card badges and static "Open Module ↗" text, elevate card anatomy with tactile hairline depth, introduce a Quick Access row for frequent modules, and correct the `MyPriviledging` UI display label to `MyPrivileging`.

**User Decision (2026-10-11 via Grill-Me Protocol):**
- Scope: Full package (Compact header, Modern Depth card anatomy, Quick Access row).
- Card Style: Streamlined tactile card with whole-card interactive lift, top hairline sheen, enlarged icons, subtle hover arrow, and removal of repeated badges / footer links.
- Header Style: Unified single-row executive bar consolidating greeting, hospital tag, staff count, and live system status.
- Typo: Update UI display title to `MyPrivileging` while preserving internal route `/priviledging`.

## Acceptance Criteria
1. **Compact Executive Bar**: Consolidate greeting (`Good evening, AMRI AMIT`), hospital badge (`Hospital Lawas`), live staff count (`86 Staff`), and system health indicator into a single space-efficient executive bar, saving ~120–150px vertical height.
2. **Streamlined Modern Depth Cards (`ModuleCard`)**:
   - Remove redundant category badges (`[CLINICAL •]`, `[LOGISTICS •]`, `[ADMIN •]`) from inside domain-grouped cards.
   - Remove repeated `Open Module ↗` text link from footer.
   - Introduce tactile hairline depth: top-edge reflection (`border-t-white/10`), surface elevation token (`shadow-elevation-1` -> `hover:shadow-elevation-2`), and fluid hover lift (`hover:-translate-y-1`).
   - Whole-card interactive affordance with subtle corner launch indicator appearing on hover.
3. **Quick Access / Frequent Modules**: Add a dedicated, compact "Quick Access" strip for high-frequency clinical modules (e.g., MyFormulari, MySuhu, MyPrepacking, MyKunci) enabling instant 1-click muscle memory launch.
4. **Typo Correction**: Display label updated from `MyPriviledging` to `MyPrivileging` in UI without breaking existing `/priviledging` routes or database logs.
5. **Code & Rule Gate**: Zero new mock data, `scripts/check-rules.cjs` PASS, and `npm run build` PASS.
