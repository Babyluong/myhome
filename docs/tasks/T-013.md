# T-013 — System-Wide Table Contrast, Glassmorphism Slop & Dark-Mode Legibility Overhaul

**Goal:** Eradicate washed-out grey table containers (`bg-white/40`, `bg-white/50`, `bg-white/70`), unreadable low-contrast table text (`text-slate-400`, `text-slate-600`), and dark-on-dark unreadable colored values (`text-blue-600/700`, `text-purple-700`, `text-emerald-900`) across MyCylinder and the entire application, replacing them with canonical semantic design tokens (`bg-surface`, `border-border-default`, `text-text-primary`, `text-text-secondary`, `text-text-muted`) and dual-mode high-contrast pairs (`dark:text-*`) for 100% WCAG 2.2 AA compliance in both Light and Dark modes.

**User Decision (2026-10-11 via Grill-Me Protocol):**
- Scope: Full system fix executed via a deterministic batch Node.js transform script.
- Styling standard: Strict semantic design tokens (`bg-surface`, `border-border-default`, `text-text-primary`, `text-text-secondary`) and explicit dark mode contrast classes (`dark:text-blue-400`, `dark:text-purple-400`, `dark:text-emerald-400`, `dark:text-slate-300`).
