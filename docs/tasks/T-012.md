# T-012 — Procurement Module Modern Depth & Dark-Mode Contrast Overhaul

**Goal:** Refactor the 7 pages in `src/modules/procurement/pages/procurement/` to eradicate dark-mode color pollution (muddy pastel `bg-*-50` washes on dark surfaces), eliminate over-rounded `rounded-[2.5rem]` (40px) bubble radii in favor of disciplined clinical radii (`rounded-2xl` / `rounded-xl`), unify KPI metric card surfaces, and calm high-contrast repetitive status badges to meet H.O.M.E. Modern Depth & TasteSkill clinical density (7-8).

**User Decision (2026-10-11 via Grill-Me Protocol):**
- Scope: Sliced refactoring of the entire Procurement module first (7 pages: `PurchaseOrderListPage.tsx`, `LPOListPage.tsx`, `ReceivingPage.tsx`, `OrderTrackingPage.tsx`, `SupplierPerformancePage.tsx`, `PenaltyPage.tsx`, `CreditNoteAuditPage.tsx`) using a deterministic Node.js script.

## Acceptance Criteria
1. **Unify KPI Cards to Modern Depth**:
   - Replace muddy/washed-out pastel fills (`bg-indigo-50/40`, `bg-emerald-50/50`, `bg-amber-50/50`, etc.) with canonical `--bg-surface` (`bg-surface`) containers with hairline borders (`border border-border-default` or `border-white/10`).
   - Accentuate cards through focused, accessible icon badges (`bg-cyan-500/10 text-cyan-400 border border-cyan-500/20`, `bg-emerald-500/10 text-emerald-400`, `bg-amber-500/10 text-amber-400`) instead of murky whole-card background washes.
2. **Disciplined Clinical Radii**:
   - Replace outsized `rounded-[2.5rem]` (40px) bubble corners with disciplined clinical `rounded-2xl` (16px) for major containers and `rounded-xl` (12px) for cards and inner panels.
3. **Calm Table Status Badges**:
   - Replace glaring light pill badges (`bg-emerald-50 border-emerald-100 text-emerald-700`, etc.) with dark-depth compliant pills (`bg-emerald-500/10 text-emerald-400 border border-emerald-500/20`, `bg-amber-500/10 text-amber-400 border border-amber-500/20`, `bg-cyan-500/10 text-cyan-400 border border-cyan-500/20`).
   - Improve scannability by reducing luminance glare on repetitive "APPROVED" states.
4. **Remove Light Shadow Halos in Dark Mode**:
   - Eliminate `shadow-slate-200/30`, `shadow-slate-100/40`, and `shadow-indigo-100/30` which create dirty grey halos in dark mode.
5. **Code & Rule Gate**:
   - Zero mock data introduced (R1 check).
   - Deterministic batch script execution (Fix 3 / Script-First rule).
   - `scripts/check-rules.cjs` PASS.
   - `npm run build` PASS.
