# T-009 — MyFormulari Depth Design System Alignment (Eliminating Color Sprawl)

**Goal:** Eliminate color sprawl, rainbow gradients, high-contrast light mode card glare in dark mode, and mismatched UI patterns across MyFormulari. Align all 4 sub-views to the H.O.M.E. "Depth" clinical design standard with unified headers, unified tokens, and strict semantic colors.

**User Feedback (2026-10-11):** Too much color, inconsistent with other modules across the ecosystem.

## Acceptance criteria
1. **Header Standardization**: All 4 sub-pages (`AntidoteProtocolPage`, `DrugQuotaPage`, `DrugAlternativesPage`, `AntimicrobialGuidelinePage`) use standard `PageHeader` (`src/components/ui/page-header.tsx`) or unified clinical headers. Zero rainbow/gradient top lines (`from-rose-500 via-indigo-600...`, `from-purple-600...`).
2. **Palette & Token Discipline**: Zero uncontrolled neon violet/indigo/purple buttons or AI sparkle gradients. Primary buttons and active states use `--accent-base` / Cyan-Sky or clean subtle surface styles.
3. **Strict Clinical Semantics**: Red/Rose is restricted strictly to critical emergencies/stockouts/contraindications (not "0 issues" stats). Emerald is for stable/normal. Amber is for warning/precautions.
4. **Dark Mode Cohesion & Glare Elimination**: In `NAGClinicalMonograph.tsx`, replace the blinding white dosage text boxes (`bg-white/90`) and bright pastel card backgrounds with proper dark surface tokens (`bg-surface`, `bg-subtle`, dark hairline borders).
5. **KPI Stat Consistency**: Remove pastel skittle icon containers (magenta/blue/mint/white) in `DrugQuotaPage.tsx` and `DrugAlternativesPage.tsx`. Use consistent subtle clinical surfaces.
6. **Code & Rule Gate**: `scripts/check-rules.cjs` PASS, `npm run build` PASS, 0 new mock records.
