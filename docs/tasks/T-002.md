# Task Card: T-002 — Password-Protected Store Location Switcher in Inventory

**Goal:** Implement password protection (`F@rmasi.2016`) when switching to other store locations or consolidated view in `StoreLocationSelector`, restricting cross-store inventory viewing to authorized personnel.

### Acceptance Criteria
1. Switching to a user's own registered unit store requires NO password.
2. Switching to another store or "Semua Stor (Paparan Berpusat)" prompts for password `F@rmasi.2016`.
3. Incorrect password displays clear error feedback and blocks store switching.
4. Correct password unlocks cross-store access in `sessionStorage` for the current browser session.
5. Dropdown provides an option to "Kunci Semula" (Relock) at any time.
6. Clean modal dialog adhering to Emil Kowalski motion and Impeccable dark theme tokens (no AI gradients, no layout shifts, keyboard accessible with Enter/Escape).
7. Passes `scripts/check-rules.cjs` and `npm run build`.
