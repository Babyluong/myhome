# T-008 — H.O.M.E. Design System Revamp ("Depth" language)

**Goal:** One consistent modern design language across login, hub, and all 21 router modules. Real 3D only on login and hub. Subtle depth everywhere else. Visual-only changes.

**Grill answers (2026-10-11):** Hybrid 3D · R3F + drei, lazy-loaded · dark-first with light mode, navy/slate base, one teal/cyan accent · modern desktops only · phased rollout · visual only (no route/data/service/DB changes) · rewrite R5 + design-system doc.

## Acceptance criteria
1. `src/index.css` holds the only colour/radius/elevation/motion tokens. Dark and light themes switch through `[data-theme]`. Zero hex values in changed `.tsx` files.
2. Login (`/login`) and Hub (`/hub`) render a lazy-loaded R3F scene. It falls back to a static layered background under `prefers-reduced-motion` or when WebGL is missing. The 3D chunk stays out of the module bundles (verify with `vite build` output).
3. Shared primitives `Surface`, `Button`, `DataTable`, `PageHeader`, `AppShell` live in `src/components/ui/`. Each file is ≤150 lines and styles all 6 microstates.
4. Every module page uses the primitives/tokens (codemod run). `scripts/check-rules.cjs` and `npm run build` pass. No diffs in `services/`, `hooks/`, `supabase/`.
5. Test gate PASS: login → hub → 3 sample modules, dark and light, at 1440 and 1280 widths. Screenshots go in `docs/test-reports/`.
