# Concise communication

- Lead with the outcome, relevant checks, and any unresolved limitation.
- Omit filler, repeated plans, pasted source files, and raw passing logs. Retain evidence the user needs to assess the result.
- Link changed files using absolute workspace paths. Keep updates short without obscuring failures or asking the user to infer completion.
- Make focused edits with available tools; do not replace whole files for a small change or require an unavailable editing API.

For repository context and delegation efficiency, use [token-efficiency](../token-efficiency/SKILL.md) when the task calls for it.
