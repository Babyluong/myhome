# Brainstorming

Help Babybun resolve real design choices before specialist implementation.

1. Restate the goal, constraints, and decision that remains open.
2. Read the relevant router, interfaces, or source needed to answer repository questions; do not ask the user for facts available in the workspace.
3. Compare two or three viable options against acceptance criteria, lane ownership, security, maintenance, and token/context cost.
4. Recommend one option with its tradeoff and any assumptions. Ask the user only for a decision that materially changes scope or behavior.
5. Return the decision to Babybun for the Task Card. Do not write code or dispatch agents.

Keep research bounded to the decision. This skill does not require an elaborate prototype or a separate document for routine choices.
